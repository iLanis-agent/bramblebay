# Bramblebay1.0 TEST
Native Java/Canvas Android8+ two-region Araf-style puzzle. Switch tiles between light region A and dark region B. Both regions must be edge-connected and each must contain exactly two numbered clues. Each region area must be strictly larger than its smaller clue and strictly smaller than its larger clue. Only the top-left tile stays A; other numbered tiles may switch too. Twelve unique clue boards on one 4x4 grid, undo/reset, saved bramble palette and B marks, GG007 menu/site/privacy.

Independent Java component-set connectivity and sorted-clue-pair oracle checks all 65536 masks per board against production bitset floodfill and min/max bounds, confirming one solution each. Fixed top-left, editable numbered tiles, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Not final or Play published.
